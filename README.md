# Video Downloader

A simple desktop app to download videos. Built with Python, Kivy, and yt-dlp.

## Download

Grab the latest binary from the [releases page](../../releases) or from the
landing page hosted via GitHub Pages.

## Run (Linux)

    chmod +x VideoDownloader
    ./VideoDownloader

## Build from source

    pip install yt-dlp customtkinter
    python app.py
